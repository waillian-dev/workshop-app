
## Installation & Setup

### Prerequisites

- Node.js and npm
- Git

### Getting Started

1. Clone the repository:

   git clone https://github.com/waillian-dev/workshop-app.git

2. Navigate to the project:

   cd workshop-app

3. Install dependencies:

   npm run install:all

4. Configure environment variables using
   backend/.env.example.

5. Start the development server:

   npm run dev
   ...

### Development

- Frontend: http://localhost:5173
- Backend API: http://localhost:3000
